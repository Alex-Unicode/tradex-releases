# TradEx by UNICOM — installer

TradEx è un'app desktop per Windows che unisce l'analisi tecnica (multi-chart,
indicatori, strumenti di disegno, replay) al Quadro fiscale italiano per il
regime dichiarativo: plus e minusvalenze con metodo LIFO, compensazione delle
minus, cambi BCE per i titoli in valuta, import CSV dal tuo broker.

Questo repo contiene solo gli installer. Il codice sorgente non è pubblico.

## Download

Ultima versione: **[TradEx-setup.exe](https://github.com/Alex-Unicode/tradex-releases/releases/latest/download/TradEx-setup.exe)**

L'app si aggiorna da sola: ogni aggiornamento è firmato e verificato prima
dell'installazione.

## Requisiti

Windows 10 o 11, 64 bit.

## Avviso SmartScreen

L'installer non ha ancora un certificato Windows. Alla prima installazione
compare "Windows ha protetto il PC": scegli **Ulteriori informazioni** e poi
**Esegui comunque**. Il certificato arriverà prima del lancio a pagamento.
